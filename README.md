# 🍲 Smart Recipe Assistant

Smart Recipe Assistant is a Flask-based web application designed to help users search, manage, and get personalized recipe recommendations based on available ingredients.

## 🚀 Features
- **User Authentication**: Secure Login & Registration system.
- **Recipe Management**: Add, edit, view, and delete recipes.
- **Smart Recommendations**: Get recipe suggestions based on ingredients and user preferences.
- **Admin Dashboard**: Analytics and management table for system statistics.
- **Favorites & Shopping List**: Save favorite recipes and manage ingredient shopping lists.

## 🛠️ Tech Stack
- **Backend**: Python (Flask)
- **Database**: SQLite
- **Frontend**: HTML5, CSS3, JavaScript (Chart.js for analytics)
